# Real-Time Emotion Detection System 🎭

This project is a Real-Time Emotion Detection System developed using Artificial Intelligence, Machine Learning, and Deep Learning techniques.

It detects human emotions live through a webcam feed using Computer Vision and a trained Convolutional Neural Network (CNN) model.

---

## 📌 Project Overview

The system captures video from a webcam, detects faces using OpenCV, preprocesses the image, and predicts emotions using a trained deep learning model.

Emotions detected:
- Happy 😊
- Sad 😢
- Angry 😠
- Neutral 😐
- Surprise 😲
- Fear 😨
- Disgust 🤢

---

## 🛠 Technologies Used

- Python
- OpenCV
- TensorFlow
- Keras
- CNN (Convolutional Neural Network)

---

## ⚙ How It Works

1. Webcam captures real-time video
2. Face detection using Haar Cascade
3. Face image preprocessing (grayscale, resize, normalization)
4. Emotion prediction using trained CNN model
5. Display predicted emotion on screen
